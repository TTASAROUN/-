# 접수 폼 연결 방법 (구글 시트, 약 5분)

1. 구글 드라이브에서 새 **구글 시트**를 만든다. (이름 예: `따사로운 접수`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 기존 코드를 지운 뒤 `Code.gs` 내용을 붙여넣는다.
   - 알림 메일을 받으려면 맨 위 `OWNER_EMAIL`에 이메일을 입력한다.
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나** / 액세스 권한: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL**을 복사한다. (권한 승인 창이 뜨면 허용)
4. `website/assets/config.js`의 `endpoint`에 그 URL을 붙여넣고 저장·배포한다.
5. 사이트에서 폼을 제출해 보면 시트에 폼 종류별 탭(consult, match, growth, class, branch, academy)이 자동 생성되고 행이 쌓인다.

## 성장노트 운영
- `growth` 탭의 **상태** 열: 접수 → 확인 → 해결 중 → 완료 등으로 직접 관리
- **처리결과**, **개선내용** 열에 내용을 적고, **공개승인(Y)** 열에 `Y`를 넣으면 사이트 성장노트에 표시된다.
- 공개 전 개인정보(실명·연락처·주소)가 들어 있지 않은지 꼭 확인한다.

## 주의
- 시트에는 고객 개인정보가 쌓이므로 시트 공유 범위를 관리자만으로 제한한다.
- 접수 정보는 목적 달성 후 파기한다. 개인정보처리방침 페이지는 별도로 만들어 `config.js`의 `privacyUrl`에 입력한다.

## 번개매칭 연동 (관리사 데이터)
1. 같은 구글 시트에 탭을 하나 만들고 이름을 정확히 **`관리사`** 로 한다.
2. 저장소의 `templates/관리사_데이터_양식.xlsx` 내용을 붙여넣는다. (1행 열 제목은 바꾸지 말 것)
3. Apps Script에 `Code.gs`와 함께 **`Match.gs`** 파일을 추가하고 `apps-script/Match.gs` 내용을 붙여넣는다. 이후 다시 **배포 → 배포 관리 → 새 버전**으로 업데이트한다.
4. 사이트의 번개매칭에서 조건을 고르면 시트의 `관리사` 탭에서 조건에 맞는 선생님만 목록에 나타난다.
   - 고객 화면에는 이름 첫 글자·경력·성향 등만 보이고 전화·주소·생년월일·서류는 보이지 않는다.
   - 신청하면 `match` 탭에 신청 내역(고객 정보, 선택한 선생님·관리번호)이 쌓이고 알림 메일이 간다.
5. `assets/match-core.js`(조건 로직)를 고치면 `Match.gs`에도 같은 내용을 복사한다.
