# 아토소프트 LMS vs 직접 만든 LMS — 한 장 정리

## 1. 만든 것

| 구분 | 내용 |
|---|---|
| 홈페이지 | 기관 소개, 모집 과정, 상담 신청(→ 콘솔 "입학상담"에 자동 등록), 공지, 연락처 |
| 업무 콘솔 | 아토소프트와 같은 **16개 메뉴, 63개 화면** 전부 |
| 훈련생용 페이지 | 설문 응답 링크 (로그인 없이 휴대폰으로 응답) |
| 실행 | 컴퓨터 1대에 Node.js 설치 후 `node server.js` 한 줄. 외부 프로그램 설치 없음 |
| 체험 | 서버 없이 브라우저만으로도 열림 (이 경우 데이터는 그 브라우저에만 저장) |

### 메뉴별 구현 상태  (O 그대로 됨 / △ 방식이 다름 / X 안 됨)

| 번호 | 메뉴 | 상태 | 비고 |
|---|---|---|---|
| 1 | 상담 및 접수 | O | 면접평가표 총점 자동, 등록현황 자동 집계 |
| 2 | 과정등록 | △ | 과정복사 O, 안내자료 O, 시간표는 **CSV 업로드**로 대체 (HRD-Net 자동 연동 X) |
| 3 | 학적부 | O | 신상기록부, 상담일지, 확인서류, 고충, 게시판 |
| 4 | 상담관리 | O | 과정별 / 일자별 / 훈련생별 자동 분류 |
| 5 | 훈련일지 | △ | 시간표에서 일지 자동 생성 O, 결재(작성→검토→승인) O. 단 **법적 효력 있는 전자결재 X**, HRD-Net 전송 X |
| 6 | 사전평가 | O | 평가기본정보 복사, 분석표/최종분석 자동 계산 |
| 7 | 수행평가 | O | 자가진단 설정 → 자기평가서 자동 문항, 수행준거 파일 업로드 시 자동 생성 |
| 8 | 평가관리(능력단위) | O | 종합/개별 성적표, 능력단위별 분석표, 편차비교표(Z점수), 요소별 달성률 자동 |
| 9 | 설문관리 | O | 주관/객관/선다형, 결과분석 자동, 설문복사 |
| 10 | 증서관리 | O | 증서번호 자동발급(기관코드-연도-일련번호), A4 출력/PDF, 발급대장 자동 |
| 11 | 사후관리 | O | 취업보고, 취업현황, 사후관리 현황표(취업률 자동), 확인서 관리 |
| 12 | 통합관리 | O | 현황판: 오늘 훈련일지 미작성, 결재 대기, 증서 미발급, 30일 상담 없는 훈련생, 미처리 고충 등 **업무 누수 자동 알림** |
| 13 | 인증평가자료함 | O | 폴더 트리 + 평가지표 번호 + **Viewer 모드**(메뉴 숨김, 심사위원용) |
| 14 | 커뮤니티 | O | 공지사항, 달력 스케줄러(평가·개강·마감 자동 표시) |
| 15 | 기타관리 | O | 우수교직원, 교직원, 회의록, 서식자료실, 교재/시설/장비, 기관설정, 계정 |
| 16 | 로그현황 | O | 지역별/성별/연령별/지원경로별 그래프, 상담→등록 전환율 |

공통: 모든 화면에서 검색, 정렬, CSV 내려받기, 인쇄, 첨부파일, 휴대폰 화면 지원.

## 2. 안 되는 것 (솔직하게)

| 안 되는 것 | 이유 | 대안 |
|---|---|---|
| **HRD-Net 연동** (출결·훈련일지 전송, 시간표 자동 가져오기) | 정부 시스템 연동은 등록된 업체만 가능 | HRD-Net에는 지금처럼 따로 입력. 시간표는 CSV로 올림 |
| 법적 효력 있는 전자서명·전자결재 | 공인 인증 체계 필요 | 내부 결재 기록용으로 사용, 원본은 출력 후 서명 |
| 문자/카카오 알림톡 발송 | 유료 발송 서비스 계약 필요 | 계약하면 연결은 가능 (추가 작업) |
| 24시간 고객센터, 장애 대응, 법령 개정 반영 | 사람이 없음 | 문제 생기면 저에게 요청 |
| 서버 운영·백업·보안 | 누군가 켜고 관리해야 함 | 아래 "운영 방법" 참고 |
| 검증 이력 | 새로 만든 것. 다른 기관 사용 실적 없음 | 한 달 체험 후 결정 |

## 3. 아토소프트 대비

| | 아토소프트 | 직접 만든 LMS |
|---|---|---|
| 비용 | 월 이용료 (견적 확인 필요) | 0원 + 호스팅 월 1~3만 원 (기관 PC에 두면 0원) |
| HRD-Net 연동 | O (핵심 장점) | X |
| 홈페이지 | 별도 제작(별도 업체) | 포함, 상담신청이 콘솔로 바로 들어옴 |
| 우리 기관 맞춤 수정 | 업체 요청, 유료/대기 | 파일 1개 고치면 됨, 즉시 |
| 데이터 소유 | 업체 서버 | 우리 기관 (백업 파일 1개) |
| 인증평가 대응 | 심사위원이 익숙한 양식 | 양식은 다름, 자료함 Viewer는 있음 |
| 화면 | 기능 많고 복잡 | 단순, 비전문가 기준 |
| 장애 시 | 업체 대응 | 기관 책임 |

## 4. 결론

**아토소프트를 써야 하는 경우** (하나라도 해당하면):
1. HRD-Net 이중 입력을 반드시 없애야 한다 → 이게 가장 큰 이유
2. 6개월 안에 기관 인증평가가 있고, 검증된 양식이 필요하다
3. 기관에 컴퓨터를 관리할 사람이 아무도 없다

**직접 만든 LMS로 충분한 경우**:
1. 상담·성적·증서·취업 관리 같은 **내부 기록**이 주목적이다
2. HRD-Net은 어차피 지금도 따로 입력하고 있다
3. 비용 절감과 우리 기관 맞춤이 중요하다

**추천**: 지금 만든 것을 **한 달간 실제 업무에 써 보고** 결정. 그 사이 아토소프트 견적을 받아 연 비용을 비교. 둘 다 쓰는 것도 가능 (아토소프트는 HRD-Net용, 이건 내부 관리·홈페이지용).

## 5. 운영 방법 (선택)

| 방법 | 비용 | 적합 |
|---|---|---|
| A. 기관 PC 1대에서 실행, 같은 사무실 Wi-Fi에서 접속 | 0원 | 교직원 2~5명, 사무실 안에서만 사용 |
| B. 클라우드 호스팅 (예: 가비아, 카페24, AWS 라이트세일) | 월 1~3만 원 | 외부/휴대폰 접속, 훈련생 설문 응답 |
| C. 위 B를 제가 설정 | 시간만 | 원하시면 진행 |

시작 계정: `admin / 1234` → 기타관리 > 사용자 계정에서 변경. 예시 데이터는 기타관리 > 기관 설정에서 한 번에 삭제.
