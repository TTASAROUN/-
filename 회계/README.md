# 따사로운 회계부 v2 — 사업자별 분리

- `따사로운_회계부_v2_사업자별.xlsx` : 통합서비스 / 평생교육원 두 사업자를 시트 단위로 완전히 분리한 회계부
- `build_회계부_v2.py` : 위 파일을 다시 만드는 스크립트 (openpyxl). 계정과목·통장 목록을 고친 뒤 실행하면 같은 구조로 재생성됩니다.

## 구조
| 탭 | 내용 |
|---|---|
| 요약 | 두 사업자 숫자를 나란히 보는 읽기 전용 화면 |
| 통합 ①~④ | 따사로운 통합서비스 (바우처통장 · 경비통장 · 카드) |
| 교육원 ①~④ | 따사로운 평생교육원 (교육원통장 하나) |

각 사업자: ① 거래입력 → ② 월별결산 → ③ 통장·카드 → ④ 설정(계정과목표).
사업자 사이에 오간 돈은 「타사업자 정산수입 / 정산지출」 과목으로 양쪽에 적습니다.
